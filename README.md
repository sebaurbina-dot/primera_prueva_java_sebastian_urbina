INSTRUCCIONES DE EJECUCIÓN
 
Autor: Sebastián Solano Urbina Arias
 
REQUISITOS:
- Java JDK 17 o superior.
- IntelliJ IDEA o cualquier IDE compatible con Java.
 
EJECUCIÓN DEL PROYECTO:
 
1. Abrir el proyecto en IntelliJ IDEA.
2. Esperar que el IDE cargue todos los archivos.
3. Abrir el archivo Main.java.
4. Ejecutar el proyecto presionando el botón Run (▶).
5. Revisar la salida en la consola..
 
FUNCIONALIDADES IMPLEMENTADAS:
 
- Registro de bicicletas.
- Búsqueda de bicicletas por código.
- Listado de bicicletas registradas.
- Cálculo de costo de mantención.
- Gestión centralizada mediante GestorDelTallerDeBicicletas.
 
CONCEPTOS DE PROGRAMACIÓN ORIENTADA A OBJETOS UTILIZADOS:
 
- Herencia.
- Interfaces.
- Polimorfismo.
- Encapsulamiento.
- Constructores.
- Sobrescritura de métodos (@Override).
- Uso de ArrayList para almacenamiento de datos.
 
ESTRUCTURA DEL PROYECTO:
 
- Bicicleta.java (Clase padre)
- BicicletasElectricas.java
- BicicletasMontaña.java
- ConGarantiaExtendida.java (Interfaz)
- gestorDelTallerDeBicicletas.java
- Main.java
 
RESULTADO ESPERADO:
 
Al ejecutar el programa se mostrará:
 
- Registro de bicicletas.
- Búsqueda por código.
- Información de la bicicleta encontrada.
- Listado completo de bicicletas registradas.
